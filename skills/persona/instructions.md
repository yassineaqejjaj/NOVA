# Persona — method

- Build every attribute from research in the provided context and cite its label (`S1`…) in
  `citations`. An attribute without evidence carries a `rationale` stating it is an assumption.
- Prefer goals, behaviours and context over demographics; add demographics only when they change design.
- Quotes must come from context, be anonymized and keep their meaning; never fabricate a quote.
- Never include real names, contact details, employers or any identifying information.
- If research covers several distinct goal sets, describe the main one and mention the others in the
  evidence section as candidates for separate personas.
- Do not invent segment sizes, metrics or study details.
- Keep ids short and stable (`goal-1`, `frus-2`, `beh-3`).
