# Technical Design — method

- Ground the content in the provided context and cite labels (`S1`…) in `citations`; items without evidence carry a one-sentence `rationale`.
- Do not invent existing systems, versions or SLAs: describe them only from context, otherwise state assumptions.
- Name components concretely; avoid generic boxes such as 'backend'.
- Ids short and stable (`goal-1`, `alt-2`, `nfr-3`, `risk-1`, `ms-1`, `q-1`).
- Owners are roles unless a person is named in context. Never invent facts, figures, dates or decisions.
