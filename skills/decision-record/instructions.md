# Decision Record — method

- Record facts from the user's input and the provided context; cite labels (`S1`…) in `citations`.
  Arguments you add carry a one-sentence `rationale`.
- Never mark a decision as accepted unless context or the user says it was taken; otherwise it is
  proposed.
- Options must be real alternatives with honest pros and cons, not straw men.
- Negative consequences are part of the record — state them.
- If the decision supersedes an earlier one in context, say so and cite it.
- Never invent who decided, dates or meeting outcomes. Keep the record under one page.
- Keep ids short and stable (`opt-a`, `dec-1`, `fu-1`).
