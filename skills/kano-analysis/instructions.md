# Kano Analysis — method

- Base classifications on research or survey data in the provided context and cite labels (`S1`…) in
  `citations`. Classifications without data carry a `rationale` and are listed as assumptions.
- Use the Kano evaluation table when survey answers exist (A attractive, O one-dimensional/performance,
  M must-be, I indifferent, R reverse, Q questionable); compute Better/Worse coefficients exactly.
- Never fabricate survey counts or percentages.
- Consider segments: the same feature can be must-be for experts and attractive for newcomers — say so.
- Mention drift: delighters offered by competitors are likely to become must-be.
- Keep item ids stable and reuse the ids of features found in context.
