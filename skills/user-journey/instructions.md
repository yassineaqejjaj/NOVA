# User Journey Map — method

- Build the journey from research, feedback and analytics in the provided context; cite labels (`S1`…) in
  `citations`. Steps or emotions you infer carry a one-sentence `rationale`.
- Map the current state (what happens today), not the ideal future, unless the user asks otherwise.
- Include steps outside the product (e.g. asking a colleague, searching for help) when evidence shows them.
- Emotions must be justified by evidence or flagged as assumptions; avoid making every step negative.
- Opportunities are needs ("know whether the import succeeded"), not features.
- Do not invent funnel figures, quotes or names.
- Keep ids short and stable (`step-1`, `opp-import`).
