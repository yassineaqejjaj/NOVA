# Experiment Analysis — method

- Use only results present in the user's input or the provided context; cite labels (`S1`…) in
  `citations`. If results are missing, say so in the summary and do not estimate them.
- Never fabricate numbers, p-values, intervals or sample sizes; never compute significance from
  incomplete data — state what is missing instead.
- Judge the result against the threshold and decision rule set before the test; if none existed, say so
  and lower confidence.
- "Not significant" is not "no effect": report inconclusive results as such.
- Segment findings are hypotheses for future tests unless the test was powered for them.
- Keep ids short and stable (`res-primary`, `ins-1`, `dec-1`).
