# Impact / Effort Prioritization — method

- Take items and any evidence on value or cost from the user's input or the provided context; cite labels
  (`S1`…) in `citations` on the items they inform.
- Impact is judged against the stated objective only; say which one in the summary.
- Spread the scores: if everything is 3–4, the matrix tells nothing — rescale relative to each other.
- Effort includes everything to ship (design, build, test, rollout), not just coding.
- Never invent estimates or metrics presented as facts; each item has a one-sentence `rationale`.
- Recommend a more rigorous method (RICE, WSJF) for big bets when stakes are high.
- Keep item ids stable and reuse the ids or keys of items found in context.
