# Definition of Done — method

Only the Definition of Done section is written; the purpose and ready sections stay untouched.
- Start from existing standards, release process, incidents and non-functional requirements in the
  provided context; cite labels (`S1`…) in `citations`. Generic criteria carry a one-sentence `rationale`.
- Each criterion is verifiable ("Automated tests cover the acceptance criteria and pass in CI"), not
  aspirational ("good quality").
- "Done" means releasable: deployed to a production-like environment, documented and accepted.
- If incidents in context show a recurring gap, add a criterion that would have caught it and cite it.
- Do not invent tools, coverage thresholds or standards the team has not adopted; propose them as such.
