# North Star Metric — method

- Ground the value proposition and usage patterns in the provided context; cite labels (`S1`…) in
  `citations`. Proposed metrics carry a one-sentence `rationale`.
- The North Star measures value received by customers (e.g. "projects completed per active team per
  week"), not revenue, sign-ups or page views.
- Define metrics precisely enough that two analysts would compute the same number.
- Input metrics must be movable by a team within a quarter; if not, decompose further.
- Never invent baselines, targets presented as agreed, or data sources. Leave them empty when unknown.
- If a North Star already exists in context, evaluate it before proposing a replacement.
- Keep ids short and stable (`nsm`, `input-frequency`, `guard-quality`).
