# Feedback Synthesis — method

- Synthesize only feedback present in the provided context or the user's input; cite labels (`S1`…) in
  `citations` on every theme and quote. If little feedback is available, say so and lower confidence.
- Count, don't guess: frequency is a count of distinct sources or a share; never invent percentages.
- Distinguish the problem users describe from the solution they request.
- Quotes are faithful to the source and stripped of personal or company identifiers; never fabricate one.
- A single vocal customer is an anecdote unless severity justifies attention — say which.
- Keep ids short and stable (`theme-1`, `quote-1a`, `opp-2`).
